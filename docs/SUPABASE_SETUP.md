# Supabase Integration & MCP Server Guide for Finathon

This guide covers setting up **Supabase** as the primary hosted PostgreSQL database and configuring the **Supabase Model Context Protocol (MCP)** server for AI-driven database operations.

---

## 1. Why Supabase for Finathon?

- **Zero-Maintenance Hosted PostgreSQL**: Instant cloud database with automated backups and connection pooling.
- **Fast Build Time**: Meets the requirement to deploy the full database within 1–2 hours.
- **AI Tooling via MCP**: Connects the AI coding assistant directly to your live Supabase project to query schemas, execute migrations, and inspect data.
- **Next.js Ready**: Native `@supabase/ssr` support for server and client components.

---

## 2. 60-Second Supabase Setup

### Step 1: Create a Project
1. Go to [supabase.com](https://supabase.com) and log in.
2. Click **New Project**, choose an organization and name (e.g., `finathon-prod`).
3. Select your closest region and set a strong database password.

### Step 2: Run the Users Table Migration
In the Supabase Dashboard, open the **SQL Editor** and execute:

```sql
-- Create users table
CREATE TABLE IF NOT EXISTS public.users (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Case-insensitive index for fast email lookups
CREATE INDEX IF NOT EXISTS idx_users_email ON public.users(LOWER(email));

-- Optional: Enable Row Level Security (RLS)
ALTER TABLE public.users ENABLE ROW LEVEL SECURITY;

-- Allow service role full access
CREATE POLICY "Service role has full access" ON public.users
    FOR ALL
    TO service_role
    USING (true)
    WITH CHECK (true);
```

### Step 3: Copy Credentials to `backend/.env`
In **Project Settings**:
1. **Database > Connection string > URI**: Copy the pooled connection string to `DATABASE_URL`:
   ```env
   DATABASE_URL=postgresql://postgres.yourprojectref:yourpassword@aws-0-us-east-1.pooler.supabase.com:6543/postgres
   ```
2. **API > Project URL & Keys**:
   ```env
   SUPABASE_URL=https://yourprojectref.supabase.co
   SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   ```

Once added, the Node.js Express backend will automatically persist all registrations and logins to Supabase!

## 3. Supabase Model Context Protocol (MCP) Server

The **Supabase MCP Server** enables AI assistants to inspect your database schema, manage migrations, and query project resources using the standard MCP protocol.

### Configuration (`mcp_config.json`)

The project includes `mcp_config.json` pre-configured with two MCP options:

```json
{
  "mcpServers": {
    "supabase": {
      "command": "npx",
      "args": [
        "-y",
        "@supabase/mcp-server-supabase"
      ],
      "env": {
        "SUPABASE_ACCESS_TOKEN": "${SUPABASE_ACCESS_TOKEN}",
        "SUPABASE_PROJECT_REF": "${SUPABASE_PROJECT_REF}"
      }
    },
    "supabase-postgres": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-postgres",
        "${DATABASE_URL}"
      ]
    }
  }
}
```

### Obtaining MCP Credentials
1. **`SUPABASE_ACCESS_TOKEN`**: Generate a Personal Access Token from [Supabase Account Tokens](https://supabase.com/dashboard/account/tokens).
2. **`SUPABASE_PROJECT_REF`**: Found in your project URL: `https://supabase.com/dashboard/project/<PROJECT_REF>`.

### Running the MCP Server
You can launch the server directly from the terminal:
```bash
# Using project ref and personal access token
export SUPABASE_ACCESS_TOKEN="sbp_xxxxxxxxxxxx"
export SUPABASE_PROJECT_REF="your-project-id"
npx -y @supabase/mcp-server-supabase

# Or using the direct Postgres connection
npx -y @modelcontextprotocol/server-postgres "$DATABASE_URL"
```

## 4. Next.js Integration with Supabase

If your Next.js frontend interacts directly with Supabase, install the client libraries:

```bash
npm install @supabase/supabase-js @supabase/ssr
```

### Browser Client (`lib/supabaseClient.ts`)
```typescript
import { createBrowserClient } from '@supabase/ssr';

export const createClient = () =>
  createBrowserClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!
  );
```

### Server Component Client (`lib/supabaseServer.ts`)
```typescript
import { createServerClient } from '@supabase/ssr';
import { cookies } from 'next/headers';

export const createClient = async () => {
  const cookieStore = await cookies();

  return createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll() {
          return cookieStore.getAll();
        },
        setAll(cookiesToSet) {
          try {
            cookiesToSet.forEach(({ name, value, options }) =>
              cookieStore.set(name, value, options)
            );
          } catch {
            // Handled in middleware
          }
        },
      },
    }
  );
};
```
